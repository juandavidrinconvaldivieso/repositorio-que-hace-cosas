# Proyectos para nada

Cinco programas que funcionan y no sirven para nada. Solo necesitan Python 3, sin instalar librerías.

| Carpeta | Qué hace | Ejemplo |
| --- | --- | --- |
| `01_contador_de_nada` | Cuenta archivos y carpetas vacíos | `python main.py .` |
| `02_generador_de_excusas` | Inventa excusas | `python main.py 5` |
| `03_oraculo_inutil` | Responde sin ayudar | `python main.py "¿llueve?"` |
| `04_instalador_de_nada` | Instala nada con barra de progreso | `python main.py 0.5` |
| `05_piedra_mascota` | Una piedra que guarda tus visitas | `python main.py acariciar` |

Entra en la carpeta del proyecto y ejecuta el comando del ejemplo.
